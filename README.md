>
> Dengan bangga kami mempersembahkan **PDF Manager Debotz v1.9.0**, aplikasi desktop bergaya **Neo-Brutalism** yang memungkinkan pengguna mengonversi file PDF menjadi gambar berkualitas tinggi dalam format **PNG** dan **JPG/JPEG**,  mengonversikan PDF ke Docx serta kompres PDF dengan cepat, mudah, dan aman.

## 🚀 Cara Menggunakan

```text
1. Jalankan PDF Manager Debotz
2. Klik "PILIH FILE PDF"
3. Preview halaman akan muncul
4. Pilih metode ekspor
5. Pilih folder tujuan
6. Tunggu proses selesai
7. Klik "BUKA FOLDER" untuk melihat hasil
```

### 📤 Pilihan Ekspor

| Tombol            | Fungsi                       |
| ----------------- | ---------------------------- |
| 🟦 WORD FORMAT    | Ekspor PDF ke format DOCX    |
| 🟦 PNG FORMAT     | Ekspor semua halaman ke PNG  |
| 🟨 JPG FORMAT     | Ekspor semua halaman ke JPG  |
| 🟪 EKSPOR PILIHAN | Ekspor halaman tertentu saja |
| 🟪 KOMPRES PDF | Ekspor halaman tertentu saja |

---

## 📂 Format Output

Jika PDF memiliki lebih dari satu halaman, aplikasi akan otomatis membuat folder baru.

### Contoh

```text
📁 Laporan_Keuangan_PNG/
 ├── Laporan_Keuangan_hal_1.png
 ├── Laporan_Keuangan_hal_2.png
 └── Laporan_Keuangan_hal_3.png
```
